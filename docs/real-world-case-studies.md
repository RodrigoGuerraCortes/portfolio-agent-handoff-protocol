# Real-world case studies

These selected examples are grounded in archived handoff records and, for the content factory, a separately supplied production audit. The underlying tests were not rerun for this portfolio.

| Project | Recorded execution | Evidence |
| --- | --- | --- |
| Automated content factory | PostgreSQL backup repair and isolated recovery | Completed handoff; production audit reports restored 12 tables with matching counts |
| Landing Express | Generation-library stage (fourth of five in its chain) | Completed archive reports 978 full-suite tests, 8 focused tests, 4 UI tests and browser QA PASS |
| Color Vault | Exact solver and deterministic procedural generation | Completed archive reports 107 core tests, 15 widget tests and a built APK; local commit without product push |
| AHP itself | Daily/weekly operational reporting | Completed archive records 23 focused tests and read-only Markdown/JSON reporting |

## What these examples demonstrate

The backup case illustrates tightly bounded operational authorization and restore evidence. The landing-page case illustrates staged development and browser-based QA. The game case illustrates deterministic software behavior, regression testing and controlled local commits. The reporting case illustrates using the protocol to evolve its own tooling.

These are examples of application work coordinated through AHP, not proof that AHP caused every test result or that the projects achieved commercial success. No employer-specific material, internal paths, credentials or raw logs are reproduced.
